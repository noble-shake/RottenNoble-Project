# My Personal Homepage Backend
- **Environment**: XAMPP (Local), Synology NAS (Production)
- **Language**: PHP 8.x
- **Database**: MariaDB 10
- **Frontend**: React (Planned)

## 배포 방법
1. Synology NAS의 `web` 폴더로 Git Clone
2. Web Station에서 PHP 프로필 설정
3. MariaDB 데이터베이스 생성 및 연결
